## A5.8 Fitness-for-use document audits

1. Document audits verify fitness for the document's use — a handoff must
   boot a session alone; a runbook must run without the chat open — not
   only factual consistency.
2. A pointer where a procedure must be inline is an audit failure. A
   required-reading list omitting an amendment is an audit failure.
3. Mechanism: a fresh session has zero memory; it knows only what the
   pasted boot document states and what that document sends it to read.
   Any rule living solely in retired chat scrollback does not exist.
